# 180 Personal OS

Local-first PWA для планов, финансов, здоровья и аналитики на горизонте 180 дней. Интерфейс работает без аккаунта и сохраняет данные в IndexedDB; после подключения Supabase доступна авторизация и синхронизация между устройствами.

## Локальный запуск

Требуется Node.js 20+.

```bash
npm install
cp .env.example .env.local
npm run dev
```

Без переменных Supabase приложение полностью работает локально. Проверки:

```bash
npm test
npm run build
```

## Подключение Supabase

1. Создайте проект Supabase и примените `supabase/migrations/202610130001_initial.sql` через CLI (`supabase db push`) или SQL Editor.
2. В Authentication добавьте production URL в Redirect URLs и настройте email-провайдер.
3. Скопируйте `.env.example` в `.env.local` и укажите URL проекта и публичный anon key. Ключ `service_role` в браузер добавлять нельзя.
4. Перезапустите dev-сервер. В настройках приложения появится вход по magic link.

Синхронизация хранит зашифрованный транспортом JSON-снимок данных пользователя в PostgreSQL. RLS разрешает чтение и запись только владельцу. Локальные изменения сначала попадают в IndexedDB, затем отправляются в облако после восстановления соединения. В текущей версии конфликт между двумя одновременно редактирующими устройствами решается по принципу «последняя запись побеждает».

## Web Push

Push на iPhone поддерживается начиная с iOS/iPadOS 16.4 только для PWA, добавленного на экран «Домой», и после явного разрешения пользователя.

1. Создайте VAPID-пару (`npx web-push generate-vapid-keys`). Публичный ключ добавьте как `VITE_VAPID_PUBLIC_KEY` при сборке.
2. Разверните Edge Function: `supabase functions deploy send-reminders --no-verify-jwt`.
3. Добавьте секреты функции: `VAPID_PUBLIC_KEY`, `VAPID_PRIVATE_KEY`, `VAPID_SUBJECT` (например `mailto:you@example.com`). Системные `SUPABASE_URL` и `SUPABASE_SERVICE_ROLE_KEY` предоставляет Supabase.
4. Включите `pg_cron` и `pg_net`; создайте вызов функции раз в минуту по примеру в конце миграции. Авторизационный Bearer должен совпадать с `SUPABASE_SERVICE_ROLE_KEY` функции.
5. В установленном PWA откройте «Настройки» и нажмите «Включить настоящие push-уведомления».

Функция отправляет напоминания в 09:00 и 22:00 Europe/Moscow, защищается от дублей по дате и удаляет подписки, вернувшие HTTP 404/410. Нажатие открывает вкладку планов.

## Публикация и установка на iPhone

Разместите результат `npm run build` на Vercel, Netlify, Cloudflare Pages или другом HTTPS-хостинге. Для SPA должен быть fallback на `index.html`. Добавьте production URL в Supabase Auth.

На iPhone откройте HTTPS-сайт в Safari → «Поделиться» → «На экран Домой» → откройте установленное приложение. После этого включите push в настройках приложения.

## Данные и ограничения

- JSON-экспорт и импорт доступны в настройках. Перед импортом рекомендуется сделать резервную копию.
- Финансовый симулятор использует месячную ставку `годовая / 12`; это сценарий, а не банковский график. Комиссии, льготные периоды и индивидуальные правила корректируются вручную.
- Переводы не считаются доходом или расходом; получение займа компенсируется обязательством; основной долг не входит в обычные расходы, проценты входят.
- Историческая таблица капитала подготовлена миграцией. Автоматический ежедневный снимок можно добавить отдельной cron-функцией; локальные графики сейчас реконструируют движение денег из датированных операций.
- CSV-импорт и детальное разрешение конфликтов по отдельным сущностям оставлены для следующей итерации; JSON резервирует полный набор данных.
